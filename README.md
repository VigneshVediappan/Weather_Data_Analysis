# Weather Data Analysis

## Aim
To analyze daily temperature and rainfall data using R programming.

## Description
This project analyzes weather information for seven days. It calculates average temperature, maximum temperature, total rainfall, and the hottest day.

## Technologies Used
- R Programming
- Data Frames
- Statistical Functions

## Features
- Stores daily weather data
- Calculates average temperature
- Finds maximum temperature
- Calculates total rainfall
- Identifies the hottest day

## How to Run
1. Open `03_Weather_Data_Analysis.R`.
2. Run the program in RStudio or VS Code.
3. View the results in the console.

## Result
The program successfully analyzes the given weather data and displays important weather statistics.
